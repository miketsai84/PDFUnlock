# PDF 密碼移除

macOS 原生（SwiftUI + PDFKit）App，無第三方相依。

## 使用
1. 取得 App：執行 `./build.sh`（見下方「建置」），或到 Releases 下載 zip；開啟 `build/PDF密碼移除.app`
2. 拖曳 PDF 進視窗（可多個）、點擊選檔，或把 PDF 拖到 Dock 圖示
3. 輸入現有密碼 → 按「移除密碼並另存」
4. 輸出檔存在**原檔同一資料夾**，檔名 `原檔名_unlocked.pdf`（已存在則加編號，不覆蓋；原檔不變）

密碼欄位取得焦點時會自動切到英文輸入法，離開後還原。密碼含中文時請用 ⌘V 貼上。

## 建置
```bash
./build.sh   # 產生 Universal（arm64 + x86_64）的 build/PDF密碼移除.app，並自動產生圖示
```

## 行為與限制
- 支援 RC4-40/128、AES-128、AES-256 加密；輸入使用者密碼或擁有者密碼皆可。
- 頁面內容串流、連結、書籤、文件標題等資訊會保留。
- 可直接開啟但有列印／複製限制的檔案，需輸入擁有者密碼才會處理。
- 沒有加密的檔案會略過並提示。
- 已知不保留：數位簽章（解密必然使簽章失效）、表單的 `AcroForm` 根字典（欄位本身與內容仍在）。
- 僅 ad-hoc 簽章；傳到其他 Mac 時首次開啟需右鍵 →「打開」。
